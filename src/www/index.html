    Sensor

    Motion is reported straight away, and clear once nothing has moved for this long. Set an HC-SR501's time knob fully anticlockwise and its jumper to repeat (H), so this decides the timing.

    The GPIO the sensor's output is wired to (GP22 as built). Changing it restarts the device.

    Clock

    The time zone is the standard (winter) offset; summer time adds an hour. Europe: last Sunday of March to last Sunday of October. North America: second Sunday of March to first Sunday of November.

    Web Access

    A password is set.

    With a password set, the browser asks for it (any username), and updates over Wi-Fi can be sent. It's sent unencrypted, so it keeps out other people on your network rather than a determined attacker. Setup mode removes a forgotten one.

    Diagnostics

    Name

    Also its network name (name.local) and MQTT client id. Home Assistant names its sensors after it. Letters, digits, - and _; used from the next start.

    Updates

    deploy.ps1 -WiFi <name> sends a new version over Wi-Fi (with a web password set): the device tries it, and goes back to this one if it doesn't start properly.

    Restart and Reset

    Reset puts every setting on these pages back to its default (the web password too), but keeps the Wi-Fi network and the sensor pin. A factory reset also forgets the name and Wi-Fi, and starts setup mode.

    Wi-Fi Network

    Connected to …. A new network is used after a restart, on trial: if it can't connect within 5 minutes, the device goes back to this one.

    Setup mode is the other way, with no network to reach this page: the device's PicoPIR-SETUP hotspot and a page at http://192.168.4.1. Holding BOOTSEL for 5 s starts it, as does the fallback below.

    Wi-Fi Fallback

    Connecting

    MQTT lets home automation software such as Home Assistant or Node-RED see the motion.

    Broker

    A password is set.

    Topics

    {name} becomes the device name. The state is on <base>/state, and {"enabled": false} or {"clear_after_s": 30} on <base>/set changes the sensor. Topics no longer used are cleared from the broker after the restart.

    Home Assistant

    Home Assistant adds the sensor automatically (MQTT discovery): the motion, the last motion, and switches for sensing and the clear time. Turning this off removes it again. Only change the prefix if Home Assistant's has been changed.

    Clock

    The time zone, summer time and time server are on the Device tab.

    Location

    For sunrise and sunset events. East and north are positive.

    Events

    Up to 8, each turning sensing on or off, as the Detect motion switch on the Device tab does. After a restart the sensor does what the latest event said.
