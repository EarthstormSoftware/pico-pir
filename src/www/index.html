    Sensor

    Motion is reported straight away, and clear once the sensor has seen nothing for this long: 5 s to an hour.

    Wiring

    The GPIO the sensor's output is wired to: GP22 unless it's wired differently. Changing it restarts the device.

    Identity

    Also its network name (name.local) and MQTT client id. Home Assistant names its sensors after it.

    Clock

    The time zone is the standard (winter) offset; summer time adds an hour. Europe: last Sunday of March to last Sunday of October. North America: second Sunday of March to first Sunday of November.

    Diagnostics

    Reset

    Reset settings keeps the Wi-Fi network; factory reset forgets it, and the device starts its PicoPIR-SETUP hotspot: join it, then open http://192.168.4.1 to set it up again.

    Wi-Fi

    To change the Wi-Fi network or its password, hold the board's BOOTSEL button for 5 seconds: the device restarts into its PicoPIR-SETUP hotspot. Join it, then open http://192.168.4.1.

    Connection timing
    Web Access

    With a password set, the browser asks for it (any username). Forgotten it? Hold BOOTSEL for 5 seconds and complete setup, which removes it.

    MQTT lets home automation software such as Home Assistant or Node-RED see the sensor.

    Broker
    Session options
    Topics

    {name} becomes the device name. Topics no longer used are cleared from the broker after the restart.

    Home Assistant

    Home Assistant adds the device automatically (MQTT discovery). Turning this off removes it again. Only change the prefix if Home Assistant's has been changed.
